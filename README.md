# 3D End-Effector Tracking with Reinforcement Learning

This repository contains a Reinforcement Learning (RL) system that controls a simulated robotic arm (Franka Panda) to accurately track a time-varying 3D trajectory (a figure-eight/Lissajous curve) while maintaining smooth motion and handling observation noise.
